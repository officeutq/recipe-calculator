# 第1段階（かなり重要・優先度高）

### 1. useMemo

今後かなり出ます。

今：

```ts
const scale =
  targetServingsNumber /
  baseServingsNumber
```

毎回計算しています。

将来：

```txt
材料1000件
集計
検索
並び替え
```

になると重くなります。

その時：

```tsx
const total =
  useMemo(() => {
    return heavyCalculation()
  }, [ingredients])
```

を使います。

学習内容：

```txt
メモ化
依存配列
再計算防止
```

優先度：

★★★★★

---

### 2. useRef

Reactでかなり頻出です。

例えば：

```txt
追加後
↓
入力欄へカーソル戻す
```

など。

例：

```tsx
const inputRef =
  useRef<HTMLInputElement>(null)
```

```tsx
inputRef.current?.focus()
```

学習内容：

```txt
DOM参照
値保持
再描画しない変数
```

優先度：

★★★★★

---
