# レシピ計算機 要件定義

## 目的

登録済みレシピを選択し、作成量に応じて材料分量を換算できるアプリを作る。  
将来的に iOS / Android アプリ化することも見据え、スマートフォンで使いやすいUIにする。

## 画面構成

### 1. レシピ計算画面

- レシピをドロップダウンで選択できる
- ドロップダウンのプレースホルダは「レシピ名」
- 選択中レシピの説明を表示する
- 基準量は入力欄ではなく、テキストで表示する
  - 例：`基準量：4`
- 作成量を入力できる
- 作成量入力欄はラベルを廃止し、プレースホルダに「作成量」を表示する
- 入力内容カードは表示しない
- 材料欄では追加・削除できない
- 材料欄には、選択中レシピの材料と換算後の分量を表示する
- 「レシピ新規作成」ボタンを表示する
- レシピ選択中は「レシピ編集」ボタンを表示する

### 2. レシピ新規作成画面

- レシピ名を入力できる
- 説明を入力できる
- 基準量を入力できる
- 材料を追加できる
- 材料を削除できる
- 保存できる
- キャンセルでレシピ計算画面に戻れる

### 3. レシピ編集画面

- 選択中レシピの内容を初期表示する
- レシピ名を編集できる
- 説明を編集できる
- 基準量を編集できる
- 材料を追加できる
- 材料を削除できる
- 保存できる
- キャンセルでレシピ計算画面に戻れる

```ts
type Recipe = {

  baseAmount: number

}

type Ingredient = {
  id: number
  name: string
  amount: number
  unit: string
}
```

## 材料要件

材料は以下の要素を持つ。

* 材料名

  * 例：砂糖、薄力粉、卵
* 分量

  * 例：100、2、0.5
* 単位

  * 例：g、ml、個、大さじ、小さじ

材料の分量は、基準量に対する元の分量として保存する。

レシピ計算画面では、以下のように表示する。

* 材料名
* 元の分量
* 換算後の分量
* 単位

表示例：

```txt
砂糖 100g → 150g
卵 2個 → 3個
```

レシピ計算画面では材料の追加・編集・削除はできない。
材料の追加・編集・削除は、レシピ新規作成画面またはレシピ編集画面で行う。

## 数値入力要件

* 数値入力はブラウザ標準キーボードではなく、独自の数値入力モーダルで行う
* モーダルには以下のキーを表示する

  * `0`〜`9`
  * `.`
  * 1文字削除
  * クリア
  * 決定
  * キャンセル
* 計算機能は持たない

  * `+`
  * `-`
  * `×`
  * `÷`
  * `=`
    は表示しない

### 対象入力

* 作成量
* 基準量
* 材料の分量

### 入力ルール

#### 基準量・作成量

* 1以上
* 小数点不可
* 最大3桁程度

#### 材料の分量

* 0より大きい
* 小数点可
* 小数点は1つまで
* 最大6桁程度

## 実装方針

* まずはURLを分けず、画面モードで切り替える

```ts
type ScreenMode = "calculator" | "new" | "edit"
```

* レシピは配列で管理する
* 選択中レシピIDをstateで管理する
* レシピ作成・編集画面では材料追加/削除を許可する
* レシピ計算画面では材料追加/削除を許可しない
* 数値入力モーダルは再利用可能なコンポーネントにする

```txt
NumberInputModal
```

* 保存は当面 LocalStorage を利用する
* 後でAPI保存へ差し替えやすいようにする

## 追加要件

### リセットボタンの廃止

- 計算画面のリセットボタンは廃止する
- 理由:
  - 現在のリセットは保存済みレシピ全体を初期状態に戻すため、ユーザーが作成した全レシピが消える可能性がある
- 代替として、レシピ編集画面に「削除」ボタンを追加する
- 削除ボタンは、編集中のレシピのみを削除する
- 削除後は計算画面へ戻る
- 削除したレシピが選択中だった場合は、選択状態を解除する、または残っている先頭レシピを選択する

### レシピ選択ドロップダウンのプレースホルダ廃止

- レシピ選択ドロップダウンの先頭プレースホルダ「レシピ名」は廃止する
- レシピが存在する場合は、いずれかのレシピが常に選択されている状態にする
- レシピが存在しない場合は、空状態を表示する

### 材料の編集

- 現在、材料は追加・削除のみ可能
- 材料を編集できるようにする
- 対象画面:
  - レシピ新規作成画面
  - レシピ編集画面
- 編集対象:
  - 材料名
  - 分量
  - 単位
- 編集開始方法:
  - 材料一覧の各材料に「編集」ボタンを表示する
- 編集時の動作:
  - 編集対象の材料を入力欄に反映する
  - 追加ボタンを「更新」ボタンに切り替える
  - 更新後、入力欄をクリアし、追加モードに戻る
- 編集キャンセル:
  - 編集中の場合は「キャンセル」ボタンを表示する
  - キャンセルで入力欄をクリアし、追加モードに戻る

### 説明欄フォームの追加

- レシピ新規作成画面・レシピ編集画面に説明欄の入力フォームを表示する
- 説明欄は複数行入力できる textarea とする
- 説明は空でも保存できる
- 計算画面では、選択中レシピの説明を表示する
